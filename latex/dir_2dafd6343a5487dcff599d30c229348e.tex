\doxysubsection{Detailed Description}
\hypertarget{dir_2dafd6343a5487dcff599d30c229348e_autotoc_md3}{}\doxysubsection{\texorpdfstring{Supercluster.\+KDTree}{Supercluster.\+KDTree}}\label{dir_2dafd6343a5487dcff599d30c229348e_autotoc_md3}
This is a \href{https://en.wikipedia.org/wiki/K-d_tree}{\texttt{KD-\/\+Tree}} written completely in C\#. This project originally started as a fork of the KD-\/\+Tree Written by \href{https://github.com/codeandcats}{\texttt{Codeand\+Cats}}, however, the structure and intention of this project has changed drastically from its origin.\hypertarget{dir_2dafd6343a5487dcff599d30c229348e_autotoc_md4}{}\doxysubsection{\texorpdfstring{About the Project}{About the Project}}\label{dir_2dafd6343a5487dcff599d30c229348e_autotoc_md4}
This is a KD-\/\+Tree that is optimized for machine learning applications, {\bfseries{however, it can used for less intensive purposes as well}}. (In fact, I am writing this for my machine learning library \href{https://github.com/eric-regina/Supercluster}{\texttt{Supercluster}}) In machine learning data-\/sets are often built, re-\/built, and built again. Also, in machine learning, algorithms need to be {\bfseries{fast}} for look ups but it is more acceptable to be slow for construction. Thus the tree bas been designed with this philosophy in mind. General characteristics are:\+


\begin{DoxyItemize}
\item {\bfseries{The tree is extremely fast for search.}}
\begin{DoxyItemize}
\item For a 10,000 3-\/nearest-\/neighbor searches on a 1,000,000 node 2-\/Dimensional tree using floats is about 7.\+5 times than the KD-\/\+Tree by \href{https://github.com/codeandcats}{\texttt{Codeand\+Cats}} (number based off of a 1,000,000 sample independent T-\/test for mean comparisons, equal variance assumed).
\item The nearest-\/neighbor list is a custom data structure (called a Bounded\+Priority\+List) that remains sorted and has O(log n) insert, but it is often much faster than O(log n) as an item is ignored if it is larger than the lists current max-\/element.
\item Utilizes .NET\textquotesingle{}s new \href{https://msdn.microsoft.com/en-us/library/system.runtime.compilerservices.methodimploptions.aspx}{\texttt{aggressive inlining}} optimization {\itshape where appropriate}.
\item The KD-\/\+Tree is implemented as an array. Index arithmetic is used to traverse nodes. This is faster (only slightly, but a statistically significant difference) than traversing node objects. This also leads to less memory usage.
\item The tree is built in the standard-\/way using an exact median finding algorithm. This is slower than the \href{https://en.wikipedia.org/wiki/Quickselect}{\texttt{quickselect}} or \href{https://en.wikipedia.org/wiki/Median_of_medians}{\texttt{median-\/of-\/medians}} algorithm but is more likely to create a balanced tree. This allows for search time to be as close to O(log n) as possible.
\end{DoxyItemize}
\item {\bfseries{There is no delete method.}} If you want to change the tree, rebuild it. Many KD-\/\+Tree implementations simply rebuild the tree to "{}balance"{} the tree after deletion. This is because balancing a KD-\/\+Tree is much more complicated than AVL or Red-\/\+Black trees. There do exist adaptive KD-\/\+Trees which auto-\/balance, look it up if you need one.
\item {\bfseries{There is no node object used in the KDTree class.}} but there is a {\bfseries{Node\+Navigator}} class which allows you to traverse the tree (or any array) using familiar, left, right, parent properties of a node.
\item The tree is generic. Only \href{https://msdn.microsoft.com/en-us/library/4d7sx9hd.aspx}{\texttt{{\ttfamily IComparable\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}}}} is required.
\item The tree requires a metric (a distance measure function) {\ttfamily Func}. KD-\/\+Trees are spatial data-\/structures and one only needs a metric function to implicitly define the \href{https://en.wikipedia.org/wiki/Metric_space}{\texttt{metric space}} in which the KD-\/\+Tree lives.
\item {\bfseries{The code is unit tested and well documented.}} Style-\/cop, unit-\/test, wiki tutorials and MSDN style docs. It\textquotesingle{}s all here.
\end{DoxyItemize}
