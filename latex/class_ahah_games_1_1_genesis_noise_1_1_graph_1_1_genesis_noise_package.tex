A packaged \doxylink{namespace_genesis}{Genesis} graph, stored as a single self-\/contained asset (no Asset\+Bundle). It embeds a clone of the source graph (as a sub-\/asset), the C\# source of any custom (non-\/package) nodes used by the graph, the source of the shaders referenced by those nodes, and the source of any property drawers referenced by shaders in the graph that are not part of the \doxylink{namespace_genesis}{Genesis} package. Shaders and drawers are stored as source text because runnable Shader/\+\+Drawer objects cannot live as sub-\/assets; the receiver reimports them.
