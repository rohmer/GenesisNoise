# Mirror

> ✔ Reflect UVs across X and/or Y

![Mirror](../_images/transform/mirror.png)

## Description


 ✔ Reflect UVs across X and/or Y
✔ Optionally mirror around a custom center
✔ Wrap or clamp
✔ Deterministic, no derivatives
✔ Works for 2D / 3D / Cube textures
This is perfect for:
- Symmetry
- Pattern doubling
- Kaleidoscope bases
- Seam removal
- Procedural shape construction
