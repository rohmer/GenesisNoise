# Mesh Nodes

| Node | Description |
|------|-------------|
| [Apply Material](./apply-material.md) | Applies a material to a mesh GameObject and exposes color and texture shader properties as connectable inputs. |
| [Erode Mesh](./erode-mesh.md) | Applies thermal-style erosion to mesh vertices by moving height from steep local peaks into lower neighboring vertices. |
| [Generate LODs](./generate-lods.md) | Automatically creates a Unity LODGroup for a mesh GameObject and generates simplified meshes for lower LOD levels. |
| [Mesh Scale](./mesh-scale.md) | Applies scale to a mesh object |
| [Mesh To Volume](./mesh-to-volume.md) | Transform a Mesh into a distance field. The distance field can be either signed or unsigned depending on the mode. |
| [Noise Displace Mesh](./noise-displace-mesh.md) | Applies a noise texture to each vertex of a mesh object. |
| [Optimize Mesh](./optimize-mesh.md) | Optimizes a mesh by attempting to reduce its triangle count to a target percentage of the original mesh. |
| [Prefab](./prefab.md) | Outputs an assigned prefab GameObject for use in mesh graphs. |
| [Primitive Node](./primitive-node.md) | Create a 3D mesh primitive |
| [Save Mesh Prefab](./save-mesh-prefab.md) | Packages a mesh GameObject hierarchy, generated meshes, LODs, renderers, colliders, and materials into a saved prefab asset. |
| [Smooth Mesh](./smooth-mesh.md) | Smooths a mesh to soften sharp edges by averaging neighboring vertex positions. |
| [Subdivide Mesh](./subdivide-mesh.md) | Subdivides a mesh object to provide greater detail |
| [XYZ Noise Displace Mesh](./xyz-noise-displace-mesh.md) | Applies separate X, Y, and Z noise textures to each vertex of a mesh object. |
