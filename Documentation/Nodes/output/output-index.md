# Output Nodes

| Node | Description |
|------|-------------|
| [External Output](./external-output.md) | Export a texture from the graph, the texture can also be exported outside of unity. |
| [Mesh Output](./mesh-output.md) | Serializes a mesh from the graph as a graph sub-asset so it can be reused by Blueprint Nodes in other graphs. |
| [Texture 2D](./texture-2d.md) | Writes the graph result to a 2D texture output. |
