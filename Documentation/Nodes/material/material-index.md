| Node | Description |
|------|-------------|
| [Baked Lit](./urp-baked-lit.md) | Output a URP Baked Lit material. |
| [Complex Lit](./urp-complex-lit.md) | Output a URP Complex Lit material (metallic/specular superset of Lit). |

| [Layered Lit Tessellation](./hdrp-layered-lit-tessellation.md) | Output an HDRP Layered Lit Tessellation material (up to four layers). |
| [Lit](./urp-lit.md) | Output a Lit URP Material |

| [Simple Lit](./urp-simple-lit.md) | Output a URP Simple Lit material (specular workflow). |
| [Unlit](./hdrp-unlit.md) | Output an HDRP Unlit material. |
| [Unlit](./urp-unlit.md) | Output a URP Unlit material. |
