# Conditional Nodes

| Node | Description |
|------|-------------|
| [Aggregate End](./aggregate-end.md) | Closes a loop flow block and aggregates the loop-end input values across iterations. |
| [Branch](./branch.md) | Conditionally outputs either the true of false value depending on the condition value. |
| [Break](./break.md) | Passes the input through and requests an early exit from the current loop when the condition is true. |
| [Continue](./continue.md) | Passes the input through and skips the rest of the current loop iteration when the condition is true. |
| [Enum Switch](./enum-switch.md) | Selects one of several case inputs by using an integer selection value as a case index. |
| [For Each Start](./for-each-start.md) | Begins a for-each loop flow block over a collection input. |
| [For End](./for-end.md) | Closes a for-loop flow block. |
| [For Start](./for-start.md) | Begins a for-loop flow block. |
| [Switch](./switch.md) | Selects one of several case inputs using an integer selection index. |
| [While Do Start](./while-do-start.md) | Begins a while-do loop flow block. |
| [While End](./while-end.md) | Closes a while-loop flow block. |
| [While Start](./while-start.md) | Begins a while-loop flow block. |
