# Channel Mixer

> - Supports RGB or RGBA input

![Channel Mixer](../_images/color/channel-mixer.png)

## Description


- Supports RGB or RGBA input
- Per‑channel mixing (R from RGB, G from RGB, B from RGB, A from RGBA)
- Optional clamping
- Optional grayscale output
- Fully deterministic
- CRT‑safe
- Artist‑friendly
