# Texture Nodes

| Node | Description |
|------|-------------|
| [RGBA Split](./rgba-split.md) | Splits a texture into combined RGB and individual R, G, B, and A texture outputs. Individual channels are exposed as grayscale textures. |
| [Texture Channels](./texture-channels.md) | Wraps a texture asset or input texture and exposes the source texture's full RGBA color plus its red, green, blue, alpha, and grayscale values as separate outputs. |
| [Texture Pack](./texture-pack.md) | Packs four texture inputs into a single RGBA texture. Each input contributes its red channel to the corresponding output channel. |
