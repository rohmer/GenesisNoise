# Moss

> - Moisture retention

![Moss](../_images/wear/moss.png)

## Description


- Moisture retention
- Shadowed / occluded areas
- Surface roughness
- Crevices and cavities
- North‑facing slopes
- Ambient humidity
- Random organic clustering
