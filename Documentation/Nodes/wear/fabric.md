# Fabric

> Dedicated fabric‑specific wear model that simulates:

![Fabric](../_images/wear/fabric.png)

## Description


Dedicated fabric‑specific wear model that simulates:
- Fiber fuzzing
- Thread thinning
- Edge fray
- Dirt accumulation
- Wear along weave direction
- Micro‑pilling
- High‑frequency fiber breakup
- Directional abrasion
