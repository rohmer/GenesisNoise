Serialziable is necessary for the node to be saved in the graph. NodeMenuItem is what will show up in the node menu when you right click in the graph and select "Add Node". The string you pass in is the path to where you want your node to show up in the menu. In this case, it will show up under "Custom" and then "Example - Noise Luminosity". Defines the name and where to find the shader, needs to match the name defined in the node. The shader must be in a Resources folder somewhere in your project for it to be found by the node. Shader "Hidden/Genesis/Custom/NoiseLuminosity"

All of the input and modification properties of the shader are defined in the Properties block. The names of these properties must match the names of the properties defined in the node. The types of the properties must also match. In this example, we have a float property called "Scale" and a color property called "Color". The default values are set here as well. Properties {
// The source texture that we will be modifying the luminosity for [InlineTexture]_Source_2D("Source", 2D) = "white" {} [InlineTexture]_Source_3D("Source", 3D) = "white" {} [InlineTexture]_Source_Cube("Source", Cube) = "white" {}

// The luminosity texture that will define the change to the source [InlineTexture]_Luminosity_2D("Luminosity", 2D) = "white" {} [InlineTexture]_Luminosity_3D("Luminosity", 3D) = "white" {} [InlineTexture]_Luminosity_Cube("Luminosity", Cube) = "white" {}
}

This section will likely be the same for most shaders, it defines the subshader and the pass that will be used to render the shader. The name of the pass must match the name defined in the node. SubShader { Tags { "RenderType"="Opaque" } LOD 100

Here the variables are defined for the shader. In our example it is two input textures, so we use the TEXTURE_SAMPLER_X macro // This macro will declare a version for each dimention (2D, 3D and Cube) TEXTURE_SAMPLER_X(_Source);

// This macro will declare a version for each dimention (2D, 3D and Cube) for luminosity TEXTURE_SAMPLER_X(_Luminosity);

An example shader function: // An example shader function // This takes a color and adjusts it based on the grayscale luminance float4 adjust_Luminance(float4 color, float luminance) { // Convert the color to grayscale float gray=dot(color.rgb, float3(0.299, 0.587, 0.114)); // Calculate the difference between the desired luminance and the current luminance float diff=luminance-gray; // Adjust the color by adding the difference to each channel color.rgb+=diff; return color; }

Every shader must have this function, it is the definition of the shader that will be used to process the input textures and generate the output texture. The name of this function must match the name defined in the node. float4 genesis(v2f_customrendertexture i) { // The SAMPLE_X macro handles sampling for 2D, 3D and cube textures // Here we will sample the source to get the color and then we will sample the luminosity texture to get the luminosity value float4 source=SAMPLE_X(_Source, i.localTexcoord.xyz, i.direction);

// Returns the luminosity value float4 luminosity=SAMPLE_X(_Luminosity, i.localTexcoord.xyz, i.direction);

// We will convert the luminosity to grayscale float gray=dot(luminosity.rgb, float3(0.299, 0.587, 0.114));

float4 returnValue=adjust_Luminance(source, gray);

// We must return a float4 from out shader function return returnValue; }
