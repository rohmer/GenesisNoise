Detailed Description

"Package Graph" builds a single self-contained GenesisNoisePackage asset (no AssetBundle) that embeds:

  • a clone of the graph (as a sub-asset, with its owned sub-assets remapped onto the clone),
  • the C# source of every node in the graph whose type is not in the AhahGames.GenesisNoise namespace (bundled as TextAsset sub-assets),
  • the source of the shader assets referenced by those custom nodes (bundled as TextAsset sub-assets),
  • the C# source of any property drawers referenced by any shader in the graph that are not in the AhahGames.GenesisNoise namespace (ShaderLab [Foo] attributes resolve to a FooDrawer MaterialPropertyDrawer subclass; those are bundled as TextAsset sub-assets). The package asset is named after the graph and carries the GenesisNoisePackage icon.
