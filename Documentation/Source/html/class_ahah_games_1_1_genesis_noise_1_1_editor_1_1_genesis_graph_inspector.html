Detailed Description

Custom inspector for saved Genesis graph assets. It reuses the NodeGraphProcessor GraphInspector, which renders the exposed parameters as value fields and already skips any parameter marked as hidden (param.settings.isHidden). This replaces the default ScriptableObject inspector that showed the raw exposedParameters list (including hidden ones).
