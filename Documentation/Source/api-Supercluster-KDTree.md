# KDTree

## Classes

| Name | Description |
|------|-------------|
| [`BoundedPriorityList-1-g`](api-Supercluster-KDTree-BoundedPriorityList-1-g.md#boundedprioritylist-1-g) | A list of limited length that remains sorted by *TPriority* . Useful for keeping track of items in nearest neighbor searches. Insert is O(log n). Retrieval is O(1). |
| [`KDTree-1-g`](api-Supercluster-KDTree-KDTree-1-g.md#kdtree-1-g) | Represents a KD-Tree. KD-Trees are used for fast spatial searches. Searching in a balanced KD-Tree is O(log n) where linear search is O(n). Points in the KD-Tree are equi-length arrays of doubles. The node objects associated with the points is an array of type *TNode* . |
| [`HyperRect`](api-Supercluster-KDTree-HyperRect.md#hyperrect) | Represents a hyper-rectangle. An N-Dimensional rectangle. |
