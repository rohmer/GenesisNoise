# Mesh Examples
In this directory there are 2 different examples of *Game Ready* rock/boulder generators.  Also included is a shader for boulders.

- [Long Rocks](LongRocks.md) - An example of randomized long rocks
- [Mossy Boulders](MossyBoulders.md) - A more detailed example of using noise to perturb a mesh and generate a rock.
- [Wet Rock](WetRock.md) - A game ready boulder shader, included with Genesis Noise.
