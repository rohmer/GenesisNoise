# Complex Boulder Example
This example uses several of the Mesh nodes:
- [Primitive Node](../../Nodes/mesh/primitive-node.md)
- [Subdivide Mesh](../../Nodes/mesh/subdivide-mesh.md)
- [XYZ Noise Displacement](../../Nodes/mesh/xyz-noise-displace-mesh.md)
- [Smooth Mesh](../../Nodes/mesh/smooth-mesh.md)
- [Mesh Scale](../../Nodes/mesh/mesh-scale.md)
- [Apply Material](../../Nodes/mesh/apply-material.md)
- [Generate LODs](../../Nodes/mesh/generate-lods.md)

The rock textures are generated by a reusable graph through a [Blueprint](../../Nodes/graph/blueprint.md) node.

Several procedural noise nodes shape the mesh:
- Cells 4
- Clouds 4
- Simplex 2D
- Voronoi Noise
- Anisotropic Noise

Random values vary the displacement and final proportions:
- [Random Float](../../Nodes/function/random-float.md)
- Random Int

The graph exposes these [Parameters](../../Parameters/index.md):
- **Seed** controls the procedural variation.
- **SecondaryNoise** allows the secondary displacement texture to be overridden.
- **Color Set** selects Dark Gray, Desert, or Light Gray rock colors.

The texture inputs produced by the Blueprint are hidden parameters because they are implementation details of this graph.

This example uses the [Wet Rock](../Shaders/WetRock.md) shader.

## How it works
### Mesh creation
Processing starts with a [Primitive Node](../../Nodes/mesh/primitive-node.md), which creates a sphere named **Boulder**. The sphere is marked static and provides the base topology for the rock.

The sphere is passed to [Subdivide Mesh](../../Nodes/mesh/subdivide-mesh.md). Subdivision creates enough vertices for the following displacement stages to produce a detailed silhouette instead of only deforming the original low-resolution sphere.

### Primary displacement
The first group generates separate noise fields for the X, Y, and Z axes. These textures are supplied to an [XYZ Noise Displacement](../../Nodes/mesh/xyz-noise-displace-mesh.md) node, producing the large asymmetrical forms that establish the boulder's overall character.

The exposed **Seed** parameter drives the random and procedural inputs so another seed produces a repeatable boulder variation.

### Secondary displacement
A second [XYZ Noise Displacement](../../Nodes/mesh/xyz-noise-displace-mesh.md) stage adds smaller surface variation. Its noise can be supplied through the exposed **SecondaryNoise** parameter, allowing another texture graph or imported texture to control the secondary shape breakup.

Using two displacement stages separates the large silhouette changes from the finer surface deformation and makes each scale easier to tune.

### Mesh cleanup and proportions
After displacement, [Smooth Mesh](../../Nodes/mesh/smooth-mesh.md) runs one smoothing iteration at half strength. It preserves borders, removes pointed vertices, and recalculates normals to reduce spikes without erasing the larger rock forms.

The result is passed through [Mesh Scale](../../Nodes/mesh/mesh-scale.md). Random float values independently vary the X, Y, and Z scale, preventing the final boulder from retaining a perfectly spherical proportion.

### Texture Blueprint
The [Blueprint](../../Nodes/graph/blueprint.md) node references **Rock Texture.asset**. This keeps the material-generation graph separate from the mesh-generation graph while exposing all of the texture outputs needed by the material.

The Blueprint receives the current **Seed** and **Color Set** values. It generates these named outputs:

| Output | Usage |
|--------|-------|
| Base Color | Rock albedo and selected color palette |
| Mask | Packed metallic, ambient occlusion, height, and smoothness data |
| Normal | Tangent-space surface normals |
| Breakup | Additional small-scale rock variation |

The **Color Set** parameter provides three presets: Dark Gray, Desert, and Light Gray. Changing it alters the palette generated by the Blueprint without changing the mesh.

### Material
The Blueprint outputs are connected to [Apply Material](../../Nodes/mesh/apply-material.md), which uses the [Wet Rock](../Shaders/WetRock.md) material. The mask texture follows the channel layout required by that shader:

| Channel | Usage |
|---------|-------|
| R | Metallic |
| G | Ambient Occlusion |
| B | Height |
| A | Smoothness |

UVs are regenerated when the material is applied. This gives the procedurally displaced mesh usable texture coordinates before the rock textures are assigned.

### Mesh finalization
[Generate LODs](../../Nodes/mesh/generate-lods.md) creates four mesh LOD levels and includes a culled level. The furthest visible level is a three-quad impostor baked at 512 by 512 pixels.

The result is a textured, randomized boulder that retains its detailed mesh nearby while progressively reducing geometry and switching to an impostor at long range.
